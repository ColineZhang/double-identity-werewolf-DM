# 双身份狼人杀 · 局域网测试站 v0.3

这一版可在同一个 Wi-Fi 下由一台电脑创建房间，并由手机加入为真人玩家。电脑端房主是**独立控制台，不占六名玩家中的任何座位**。其余空位可以由自动行动的测试 Bot 填满。

## 启动

需要一台安装 Node.js 18 或更新版本的电脑（推荐 Node.js 22）。无需 npm install、数据库、域名或互联网服务。

- Windows：解压 ZIP 后双击 `start-windows.bat`。
- macOS：双击 `start-mac.command`；若遇到执行权限问题，打开终端，进入解压目录运行 `bash start-mac-linux.sh`。
- Linux：在解压目录运行 `bash start-mac-linux.sh`。
- 或者在目录下直接执行 `node server.js`。

打开电脑上的 `http://localhost:3000`，按下方步骤操作。

## 一人 + 五个 Bot 的测试步骤

1. **电脑**：点击「创建测试房间（Bot 明牌、可跳过）」。电脑成为房主控制台，但不占玩家座位。「创建六人房间」创建正常模式；发牌前可切换模式。
2. **手机**：与电脑连同一 Wi-Fi，扫码加入链接（或输入电脑页面显示的 IP 地址及房间号）。填昵称加入，手机占用 1 号位。
3. **电脑**：点击「Bot 补满六人」。将创建另外五个测试 Bot（有真人加入后，也可补剩下的空位）。
4. **电脑**：点击「随机发牌」。Bot 自动锁定两张牌的上下顺序，测试房间立即向电脑与手机展示 Bot 两张身份及复制结果。真人底牌不公开。
5. **手机**：查看自己的双身份，选择第一张并点击「确认牌序」。锁牌后通过右下角「查看我的身份」展开和关闭两张牌；刷新、阶段变化及切入后台时自动收起。
6. **电脑**：在「法官语音」面板点击「开启语音并自动主持夜间」，再点击「开始测试对局」。建议在等待室就开启，以播放选牌提示。
7. **手机**：轮到你的身份执行技能时选择目标并确认。预言家选择目标后点击「确认查验」，即可在下方看到好人/狼人结果；私人查验记录在后续阶段和刷新后保留，本夜不能换目标重复查验。
8. **电脑**：夜间按固定时间自动推进，关闭声音也会自动计时。测试房主可以使用「跳过当前阶段」「直接到天亮」「跳过当前白天 / 进入下一夜」。跳过保留已提交行动，未提交技能视为不发动、未投票视为弃票；正常模式不允许跳过。首日天亮先竞选警长，竞选结束后自动公布夜间所有掉牌者号码；以后夜末直接公布。仅无任何身份牌失效时播报平安夜。白天讨论由房主结束，放逐投票全员提交后可结算，10 秒截止后自动结算。
9. **电脑**：游戏结束可以查看全部身份复盘，并点击「返回等待室，重新发牌」开始下一局。

⚠️ **不要在同一浏览器会话中同时担任房主和玩家。** 在电脑浏览器建房，再用自己的手机浏览器扫码加入；手机会生成独立的会话。

## 本版已经实现

- 独立电脑房主，不占玩家名额；人类和 Bot 合计六个玩家。
- 添加一个 Bot、Bot 补满、清空 Bot、移出单个玩家。
- 双身份发牌、合法配对校验、1～2 金宝宝、复制人、玩家自由锁定牌序；Bot 自行确认牌序。
- 客户端只读自己的真人身份和夜间技能；测试模式额外公开 Bot 身份。首夜未公告的 Bot 掉牌状态同样暂不公开。
- 固定顺序的守卫、狼人、女巫、预言家、潜行者夜间步骤；Bot 自动选择目标或弃用。
- 首夜禁止狼刀、隐狼夜间加入、预言家当前牌查验、女巫用药、守卫保护、潜行者基础攻击、双身份逐次失效、胜负条件。
- 上警/警下私密选择、竞选发言、退水、服务器倒计时、警下投票和公开唱票。竞选平票按原帖直接无警长，不做 PK。
- 竞选与讨论阶段的合法狼人自爆、竞选自爆吞警徽、完全出局警长的警徽移交。
- 白天讨论、放逐投票、公开唱票和结算；游戏结束后显示身份复盘。
- 私人查验记录跨阶段和刷新保留，防止同夜换目标重复查验。
- 房间状态和身份写入运行电脑的 `data/rooms.json`，手机断线刷新可以重新加入自己的会话。
- 无第三方网络依赖，二维码本地生成。
- 按 `NARRATOR_SCRIPT_2023_6P_v0.2.md` 生成的离线普通话 WAV 语音包；房主单设备播放、夜间固定计时、白天公开唱票、暂停/恢复/重播。

## 法官语音

提供的 `.md` 文件是播报稿；本包使用 Windows 的 Microsoft Huihui Desktop 合成了 369 条音频，并非真人录音。已更新平安夜、简短唱票、票数结论、明确掉牌状态及退水播报；票型与掉牌文字和语音分别共用 `lib/votes.js`、`lib/losses.js` 的结构化结果。WAV 位于 `public/voicepacks/2023-6p-v02/`，日常播放不依赖 Windows TTS、互联网或付费服务。

- 在房主电脑点击开启，允许浏览器播放声音；玩家手机保持静音。一个房间只能有一个正在工作的播报页面。
- 夜间顺序为守卫、狼人、女巫、预言家、潜行者，台词结束后分别开放 20、40、30、25、20 秒操作窗口。所有夜晚使用相同台词、顺序、间隔；角色不存在、技能耗尽和首夜禁刀均不跳过。一次固定夜间正文约 4 分 21 秒，另有开局或白天结束提示。
- 首夜狼人仍能在自己的手机查看有资格的狼队成员，但不能出刀。预言家结果只在本人手机显示，公共语音只提示查看手机。
- 「暂停整场」冻结夜间、竞选、放逐投票和警徽计时，并停止玩家提交操作。「重播当前口令并保持暂停」播放后仍需点击恢复；对局中的试听也会先暂停。
- 关闭播放页面、断线或服务器重启后，语音主持会暂停；连接完全失效的检测最多需要 15 秒。重新打开房主页面并点击开启即可接续，旧页面的播放占用最多 15 秒后释放。
- 「关闭语音」只停止播放，服务端固定计时继续运行。夜间已经到第二个角色以后，需完成本夜或重新开局再开启语音。
- 夜末及竞选结束后的夜间结果自动公布。白天讨论仍由房主结束，竞选平票直接无警长。未实现的完整遗言等阶段不会仅因音频文件存在而自动执行。

修改播报稿后重新生成（需要 Windows 中文 Huihui 语音及 PATH 中的 Node.js）：

```powershell
node scripts/voice-pack-text.js
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/build-voice-pack.ps1
```

两步都完成后重启服务。`pack.json` 中的实际音频时长用于服务端计时，不能只修改台词而保留旧音频。

## 已知限制：这是测试对局，不是正式裁判系统

- Bot 使用简单的随机/条件策略，不模拟真人推理，也不保证战术合理。
- 拍刀、投降、完整遗言及论坛违规判罚尚未实现。女巫任意目标解药、第二身份激活、按牌实例保存药剂和多执行者已修复。
- 多名狼人刀口不同，按用户确认的多数票选择，平票空刀。这是本桌明确约定。
- 候选人发言不限时，由房主结束；法官语音与放逐完全出局后的遗言已接入，首夜遗言及复杂裁判细则尚未完整实现。**不能将这版当作对 2023 年规则的完全复刻。**
- 狼刀指向最后一个金宝宝也不阻止女巫用毒或潜行。所有夜间技能照常结算；本夜结算后若狼牌与金宝宝全部失效，才按用户确认的「狼刀在先」判狼人胜。
- 正常模式按完整固定窗口运行；测试模式的显式跳过属于测试加速。未提交技能视作不发动。
- 没有账号、跨网络联机或公网加密；只建议在信任的家庭 Wi-Fi 内使用，不要对公网开放 3000 端口。

## 常见问题

- 手机打不开：确认两台设备在同一 Wi-Fi（不要用隔离的访客 Wi-Fi）；允许 Windows 防火墙中 Node.js 的**私人网络**访问；手机输入的是 `http://192.168.x.x:3000` 这样的电脑地址，**不是** `localhost`。
- 端口被占用：先停止之前的 Node.js 网站进程；旧版同目录的数据可被迁移，但因房主不再占座，**旧房间会重置为等待室**。
- 如果页面显示的是旧版，请在电脑和手机上强制刷新页面。
- 电脑端关掉网页但 Node.js 进程仍运行时，房间继续保留；关掉 Node.js 后联机会中断。
