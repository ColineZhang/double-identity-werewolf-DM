# 六人双身份狼人杀 · 局域网版

一台电脑做独立房主，六名玩家用手机加入同一 Wi-Fi；房主不占玩家座位，可用 Bot 补位测试。

**本项目采用下文约定的调整版规则。** 参考来源为曼联于 2023 年发布的[《金宝宝双身份规则 新版》](https://www.mistytown.cn/forum.php?mod=viewthread&page=1&tid=10611)。原帖用于了解基础设计；与本文不一致时，以我们确认的调整为准，不直接套用其他狼人杀版型。

主要调整：**首夜可开狼刀、首夜不设潜行者阶段、预言家首夜查真实阵营、截止前可反复改票、发言不计时**。各阶段时长和具体规则如下。

## 快速开始

需要 Node.js 18+，无需安装 npm 依赖。

- Windows：双击 `start-windows.bat`。
- macOS：双击 `start-mac.command`；或运行 `bash start-mac-linux.sh`。
- Linux：运行 `bash start-mac-linux.sh`。
- 通用：在项目目录执行 `node server.js`。

电脑打开 `http://localhost:3000` → 建房 → 手机连同一 Wi-Fi 扫码加入 → 凑齐六人 → 房主发牌 → 每人选择并锁定上下身份 → 房主开始游戏。语音在电脑的「法官语音」面板开启。

手机访问电脑显示的局域网地址，不能访问手机自己的 `localhost`。房主与玩家请使用不同设备或独立浏览器会话。

## 1. 配牌、身份与胜负

**牌组共 12 张：** 村民 ×5，普通狼人、隐狼、预言家、女巫、守卫、潜行者、复制人各 ×1。

- 每人两张牌，自选第一、第二身份，锁定后不能调换。第一张先生效，失效后换成第二张；两张都失效才是**完全出局**。
- 一般只有当前身份可以使用技能。下置隐狼参与狼刀是例外，见角色表。
- **真实阵营开局确定：** 两张牌中有任一狼身份（含复制得到的狼身份）就是狼人阵营，否则为好人阵营。狼牌失效不会把本人变成好人。
- **金宝宝**是两张身份均为村民的玩家，包括「复制人＋村民」。每局恰有 **1～2 名**，开局确定；普通玩家后来只剩一张村民牌，不会变成金宝宝。
- 禁止「预言家＋狼身份」及两张原生狼牌配在一起；「复制人＋狼身份」允许。狼人阵营持有女巫时，女巫必须放第二张。

| 获胜方 | 条件 |
| --- | --- |
| 好人 | 所有狼身份牌均已失效，包括下置狼牌和复制得到的狼牌；不必把这些玩家剩余的好人牌也打掉。 |
| 狼人 | 所有金宝宝都已完全出局，即他们的两张牌全部失效。 |

**整夜技能全部结算后再判断胜负。** 如果同一夜结算后双方条件同时满足，判狼人获胜。狼刀指向最后一个金宝宝，不会提前取消女巫用毒或潜行者的行动。

## 2. 每张身份牌能做什么

| 身份 | 能力与限制 |
| --- | --- |
| 村民 | 无主动技能，参与发言和投票。 |
| 普通狼人 | 当前牌是普通狼人时加入狼队，参与选择刀口；普通狼放在第二张且尚未激活时，不入群、不参与狼刀。 |
| 隐狼 | 只要隐狼牌尚未失效，即使放在第二张，也能加入狼队并参与狼刀。只有它成为当前身份时才能自爆。**当前隐狼会被验成狼人。** |
| 预言家 | 每夜查一人，只反馈好人/狼人，不报具体角色。**游戏第一夜查真实阵营，第二夜起查当前身份阵营。** 确认后立即私密显示结果，本夜不能换目标再验。第二夜才激活的预言家也只查当前身份。 |
| 女巫 | 每张女巫牌各有一瓶解药、一瓶毒药；每晚最多使用其中一瓶。解药可救任意未完全出局者，**可自救、可首夜救、空刀夜也可用**；毒药使目标失去一张牌，除非被守卫挡住。 |
| 守卫 | 每夜可守一人，可自守或空守；同一张守卫牌不能连续两夜守同一人，空守一夜后可再守原目标。**本版守卫同时能挡狼刀和毒药。** |
| 潜行者 | 每张牌整局限用一次。只能在紧接白天的夜里，袭击自己当天放逐票投过、且尚未完全出局的人；投票时和发动时必须是同一张潜行者牌。弃票或当天没有投票目标则不能发动。伤害穿过守卫和解药。首夜无此阶段。 |
| 复制人 | 开局复制自己另一张牌的身份，两张牌依次生效。各牌的药剂、潜行次数和守卫连续守护记录独立；不会同时发动两张牌。复制狼的两张牌都算狼身份。 |

**女巫通灵：** 本张女巫牌尚未使用解药时，可看到当夜所有「指杀」的选择目标，去重后按发生顺序显示；本牌组通常就是狼队选中的刀口。目标被守住也会显示，毒药和潜行目标不在其中。用掉解药后永久失去这张牌的通灵，但剩余毒药仍可使用。

**身份切换不补行动：** 例如村民在夜末掉牌，第二张女巫此时才生效，不能回到刚才的女巫窗口补药；从下一次女巫窗口开始行动。

## 3. 夜晚流程与技能结算

| 顺序 | 行动窗口 | 首夜是否进行 |
| --- | ---: | --- |
| 守卫 | 10 秒 | 是 |
| 狼人 | 40 秒 | **是，可以开刀** |
| 女巫 | 30 秒 | 是 |
| 预言家 | 10 秒 | 是，查真实阵营 |
| 潜行者 | 10 秒 | **否，整段播报和等待都省略** |

这些是口令结束后的操作时间。角色死亡、无人行动或女巫没药，不缩短该夜应有的窗口。最后一段结束后，服务器自动结算并天亮。

- 狼队每夜合计一刀，不是每名狼人各一刀。按目标所得最高票决定刀口；**最高票平票则空刀**。可以主动空刀，空刀选择不算给任何目标的一票。
- 技能目标须未完全出局；狼人可以自刀。技能窗口内可修改尚未结算的选择，预言家已确认的查验除外。超时未提交视为不发动。
- 夜末伤害依次结算：**狼刀 → 毒药 → 潜行**。每次未被抵消的伤害使当前一张牌失效，多次伤害可能在同一夜打掉两张。
- **同守同救会让两种保护都失效。** 这不会凭空增加伤害；但解药仍消耗，女巫仍失去通灵。守卫正常生效时，能挡住同夜落在该目标身上的狼刀和毒药；解药只挡狼刀，不挡毒或潜行。

下面均假设目标原有两张牌，没有其他技能影响：

| 同一目标收到的技能 | 本夜掉牌数 |
| --- | ---: |
| 狼刀 | 1 |
| 狼刀＋守卫，或狼刀＋解药 | 0 |
| 狼刀＋守卫＋解药 | 1 |
| 守卫＋解药，没有伤害 | 0 |
| 毒药＋守卫，或狼刀＋毒药＋守卫 | 0 |
| 狼刀＋毒药，无保护 | 2 |
| 狼刀＋毒药＋解药 | 1（毒药） |
| 潜行＋守卫或解药 | 1 |

## 4. 第一天：先竞选警长，再公布夜间结果

**首夜 → 天亮 → 警长竞选、唱票及结果 → 公布首夜掉牌 → 白天讨论。** 第二天起，天亮直接公布上一夜结果，不再竞选警长。

1. **报名 10 秒：** 选择上警或警下，未选视为警下；报名结束前不公开各人的选择。
2. **竞选发言不限时：** 在候选人中随机抽起点与方向，并播报顺序。顺时针按号码递增，逆时针递减。房主手动结束整个发言阶段，不追踪谁正在说话。
3. **退水与自爆窗口 10 秒：** 发言期间及这个窗口内均可退水；退水实时播报，不能重新参选。退水者从发言顺序移除，原点数和方向不重摇。
4. **警长投票 30 秒：** 只有报名结束时留在警下的人能投票，退水者也不能投。可弃票，不能投已退水的人。
5. 唯一最高票当选；**平票直接无警长，不进行 PK**。只剩一名候选人时直接当选；无人参选、全员弃票或多人参选但没有警下选民时，无警长。

首夜结果公布前，按夜间结算前的公开状态参与竞选，不通过座位、剩余牌数或投票资格提前泄露死讯。若当选者在首夜已完全出局，公布结果后处理警徽移交。

## 5. 白天讨论、放逐、自爆与遗言

**讨论与顺序：** 没有警长时，在未完全出局玩家中随机抽发言起点和方向；有警长时由现场组织。随机结果保存，刷新不重摇。发言不限时，由房主结束并开启放逐投票。

**放逐投票 10 秒：** 未完全出局者每人一票，警长也是一票，可弃票。结算前且未到截止时间可反复改票；全员提交后房主可提前结算。票型只在结算后公开，按号码唱票，并报得票数和结果。

- 唯一最高票失去当前一张身份牌，不一定完全出局。
- 最高票平票时，若警长投给其中一人，就放逐该人；否则无人被放逐。全员弃票也无人被放逐，不进行 PK。
- 警徽不算身份牌。警长只掉第一张牌仍保留警徽；完全出局且游戏继续时，可在 30 秒内移交给未完全出局者，或放弃；超时视为放弃，此后不再补选。

**自爆：** 当前身份是普通狼人或隐狼，才可在普通讨论、竞选发言或最后退水窗口自爆；下置隐狼不能自爆。通常失去当前狼牌，结束白天进入黑夜；若已达胜负条件则结束游戏。竞选期间自爆使本局警徽流失，仍须公布首夜结果。特殊情况：首夜已失效、但尚未公布的当前狼牌仍可在竞选时自爆；此时不再扣第二张，也不跳过随后的白天讨论。

**遗言：** 仅首夜或白天两张牌都失效时有遗言，**自爆没有遗言**；只掉第一张牌没有遗言。放逐完全出局后，网站进入不限时遗言，由房主点击结束，再处理必要的警徽移交并入夜；若游戏已达胜负条件，则在遗言后结束。首夜完全出局者的遗言由现场安排，目前尚无专用等待按钮。

## 6. 公告、私密信息与复盘

- 夜间只掉第一张也要公告；同一夜掉两张时，号码只报一次，并明确剩一张还是完全出局。只有无人掉牌才报「平安夜」，不公开失效牌的具体角色。
- 玩家卡片公开剩余两张、一张或已出局，以及警徽归属。夜间变化在规定公告时点更新。
- 真人底牌和查验、通灵等信息只给本人。「查看我的身份」可随时展开或收起，刷新会收起；房主对局中不能查看真人底牌。
- 结束后电脑和手机均公布全员上下身份，按「第一夜 → 第一天 → 第二夜……」简短复盘实际技能、夜间掉牌、白天票型与放逐结果。未用技能者省略，**狼队空刀也记录**。旧存档缺失的历史不补造。

## 测试模式与语音

选择「创建测试房间」可用 Bot 补位。发牌锁定后，所有参与者能看到 Bot 的两张身份、复制结果及行动；真人底牌仍私密。Bot 仅使用简单策略，不模拟真人推理。

测试房主可「跳过当前阶段」「直接到天亮」「跳过当前白天 / 进入下一夜」；已经提交的行动仍结算，未提交按不发动或弃票处理。普通房间没有这些跳过控制。

法官语音为本地合成 WAV，**1.5 倍速**，只在电脑房主端播放，不依赖互联网。暂停会冻结流程与操作；重播后仍保持暂停。「关闭语音」只关声音，服务端计时继续。播放端断线或服务重启后，已启用的语音主持会暂停，需房主恢复。

## 使用与开发说明

- 手机无法连接：确认同一 Wi-Fi、没有访客网络隔离，并允许 Node.js 的私人网络防火墙访问。
- 状态保存在 `data/rooms.json`。更新代码后重启 Node 服务并刷新电脑、手机；规则或时间轴变更建议新开局。
- 当前尚未实现首夜遗言专用阶段、投降、拍刀及论坛违规判罚；这些不能因原帖提到就视为网站已支持。
- 历史文档保留当时记录。最新已确认玩法以本文为准；修改记录见 [10 月 30 日](docs/CHANGE_REPORT_2026-10-30.md)、[10 月 31 日](docs/CHANGE_REPORT_2026-10-31.md)。

```bash
node server.js
npm test
```

可选浏览器检查：安装 Chrome/Edge 并使用 Node.js 22+，运行 `node test/browser-smoke.js`。测试使用独立临时数据。

修改语音后，用安装了中文 Huihui 语音的 Windows 电脑依次运行下面两步，再重启服务；台词、音频和实际时长必须同步：

```powershell
node scripts/voice-pack-text.js
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/build-voice-pack.ps1
```
