# 六人双身份角色交互审计

> 审计后用户规则变更：预言家首夜查真实阵营，第二夜起查当前身份。下文关于当前身份查验的原始审计结论仅适用于第二夜及以后；不再作为首夜规则。已新增确定性测试验证同一潜伏狼在首夜/第二夜的不同结果、复制狼、隐狼、好人，以及延后激活预言家。

日期：2026-10-30。范围是当前六人牌组的八种身份，以及警长。其他版型中的猎人、骑士、奇迹商人等不能因参考资料出现就加入本局。

## 资料与适用边界

- [2023 原帖](https://www.mistytown.cn/forum.php?mod=viewthread&page=1&tid=10611)：采用其六人牌组与特殊技能。守卫防毒、当前身份与实际阵营的区别、复制人的独立资源必须按本版本处理。
- [普通局守卫说明](https://www.langrensha.net/strategy/2022031502.html)及[同守同救、同守同毒说明](https://www.langrensha.net/strategy/2020120401.html)：普通版本的守卫不能挡毒；这是与本局的重要差异。不能把同守同救简化为脱离实际伤害的直接死亡指令。
- [普通法官流程](https://www.langrensha.net/strategy/2021092601.html)：用于核对夜间、竞选、公告、讨论、投票的衔接。该来源的 PK 不覆盖用户已确认的本局平票无警长。
- [女巫自救版本说明](https://www.langrensha.net/strategy/2022121302.html)：自救限制有不同版本；本项目采用用户指定的全程自救、任意合法目标解药。
- [胜负说明](https://langrensha.net/news/20240905-8.html)：结合用户确认，整夜行动结算完毕，双方同夜达标才按狼刀在先判狼胜；不能取消后续毒药或潜行。
- [新天鹅堡中文基础说明书](https://www.gokids.com.tw/tsaiss/gokids/rules/werewolves_rules_cns-1.pdf)：用于理解基础角色和昼夜结构。其女巫同夜双药、警长两票、死后亮牌等不能套到本项目；“普通规则”并非唯一版本。

## 逐牌检查结果

以下是本项目代码与回归测试检查记录，并非新增角色设计。

| 身份 | 核查重点 | 当前代码与验证 |
| --- | --- | --- |
| 村民 | 无主动技能；两张有效身份均为村民时是金宝宝 | 配牌测试检查金宝宝数量；不能将金宝宝当作额外技能角色 |
| 普通狼人 | 入群、刀口、自爆与第二身份 | 潜伏的普通狼没有刀权和自爆权；狼牌激活后才能获得对应权限。首夜不刀；多数票、平票空刀已有确定性测试 |
| 隐狼 | 非当前身份的入群例外；查验与自爆仍看当前身份 | 新测试验证：隐狼在下面时可参与狼刀，但上面是村民则验好人且不能自爆；隐狼成为当前身份才验狼人、可自爆。不能照搬别的版型“隐狼永远验好人” |
| 预言家 | 查验反馈、信息私密、重复确认 | 已有测试验证当前表面阵营、立即私密返回和持久化、一晚不能换目标重复查验；新测试覆盖复制狼两张牌均验狼人 |
| 女巫 | 第二身份激活、药剂实例、通灵与解药分离 | 既有确定性测试覆盖自救、空刀救人、先掉第一身份再行动、用解药失去通灵但保留毒药、复制女巫资源独立；当夜晚于窗口才激活，不补行动 |
| 守卫 | 连续两夜限制与空守、复制、毒药交互 | 修复空守没有清除上次守护对象；新测试覆盖隔夜可再守、连续夜不能同守、复制身份独立，以及守刀、守毒 |
| 潜行者 | 当天投票对象、同一身份实例、限定次数、致死伤害 | 修复沿用往日投票；新测试覆盖投掉目标第一牌后仍可潜行、当天无投票则无资格、换成复制潜行者不能继承选票、穿过保护 |
| 复制人 | 复制自己另一张牌，资源独立而非两张牌同时行动 | 检查 effectiveRole 与当前身份分离；测试覆盖双狼查验、女巫两套药、守卫独立选择记录、潜行者不能继承上一张牌的选票 |
| 警长（非身份牌） | 竞选、票权、完全出局移交与自爆 | 既有竞选测试覆盖退水、平票无警长、放逐破平票、警徽移交；本轮修复最后狼牌竞选自爆跳过首夜公告 |

## 实际执行的伤害组合测试

下表针对同一玩家，没有其他伤害；“掉牌”只计本夜新增失效牌，不等同于玩家必然完全出局。每行均有确定性测试。

| 同一目标收到的作用 | 新增掉牌数（原有两张可用牌） |
| --- | ---: |
| 狼刀 | 1 |
| 狼刀 + 守卫 | 0 |
| 狼刀 + 解药 | 0 |
| 狼刀 + 守卫 + 解药 | 1 |
| 守卫 + 解药，没有任何伤害 | 0 |
| 毒药 + 守卫 | 0 |
| 狼刀 + 毒药 + 守卫 | 0 |
| 狼刀 + 毒药，无保护 | 2 |
| 潜行 + 守卫 | 1 |
| 潜行 + 解药 | 1 |
| 狼刀 + 潜行 + 守卫 + 解药 | 2 |
| 毒药 + 潜行 + 守卫 | 1 |

解药和守卫冲突时消除的是保护，并不凭空添加伤害。解药已经消耗，女巫也失去该牌的通灵。守卫挡毒是本版明确特例；潜行不属于女巫通灵反馈的指杀。测试中的“狼刀、毒药掉两张”也验证了损失先后，第二张牌不能反过来补用已过去的行动窗口。

当前六人牌组只有一张复制人，它复制持有者自己的另一张牌。因此复制女巫是同一玩家两张依次生效的女巫牌，不会凭复制人同时造出两名当前女巫。引擎对多个执行者的容错测试不代表六人局应发出额外身份牌。

## 本轮实修

先新增测试，原代码出现三项失败，再修改 `lib/game.js`：

1. 守卫空守也更新该牌的上一夜选择，解除对更早目标的错误禁止。
2. 放逐选票记录游戏日；潜行资格必须匹配当天。旧 v3 存档可从已保存的放逐结果取得日期，不把旧票当成新一天选票。
3. 竞选自爆通过天亮公告流程完成胜负判定，保证吞警徽、首夜公告、胜负的事件顺序。

新增 `test/role-interactions.test.js`：22 项确定性用例。`npm test` 实际结果：70 通过、0 失败。已有 API 权限、持久化、自动时钟、语音、前端与 Bot 测试也通过。测试证明所列场景，不能据此声称所有可能组合已被穷尽。

## 用户本轮确认与剩余缺口

- 狼刀最高票目标生效，平票空刀；弃刀不计作某个目标的票。投票截止前允许反复修改。
- 白天发言由玩家自行组织，不新增自动轮流发言管理。
- 遗言按原帖的首夜/白天、两牌完全出局条件；用户明确自爆不留遗言。
- 放逐完全出局的不限时遗言已实现，由房主结束后继续；首夜完全出局的遗言专用流程仍未实现。
- 未完成：投降与拍刀。没有用自创快捷胜负判定替代这些功能。
- 实体手机同 Wi-Fi、锁屏与音频表现仍需现场验收；本轮未重复进行真机测试。

本轮没有剩余的刀口算法、改票或日间发言规则疑问；上述未完成功能是实现缺口，不能混称为规则已经确认等于功能已完成。
