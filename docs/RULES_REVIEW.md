# 规则核对与本次修订

核对日期：2026-10-30。规则有不同版本，不能把某个平台的约定当成通用且唯一的标准。本次修订以 `CODEX_CHANGE_REQUEST_2026-10-30.md` 为准。

## 通常的对局结构

准备与发牌 → 私密确认身份 → 夜间依次行动并反馈 → 首日警长竞选 → 公布夜间结果 → 白天讨论 → 放逐投票与唱票 → 处理出局、警徽及角色技能 → 下一夜，直到满足所选版型的胜负条件。

一般面杀竞选会区分报名、竞选发言、退水、投票、结果。报名后的退水不等同于原本就在警下；报名和选票也不应在提交过程中逐个泄露。发言顺序和倒计时需要桌上约定。可参考[烂柯游艺社规则的游戏进程章节](https://lanke.fun/wp-content/uploads/2023/10/%E7%83%82%E6%9F%AF%E6%B8%B8%E8%89%BA%E7%A4%BE%E7%8B%BC%E4%BA%BA%E6%9D%80%E6%B3%95%E5%85%B8.pdf)。这份资料是一套社团规则，并非所有狼人杀版本的统一裁判标准。

常见规则有警长平票 PK，但 PK 投票资格、退水范围、自爆窗口、单爆或双爆吞警徽存在版本差异。参考[警长竞选说明](https://www.langrensha.net/strategy/2022102601.html)及[平票处理说明](https://www.langrensha.net/strategy/2020122202.html)，不能据此把普通局的全部机制直接加到双身份局。

## 本项目沿用的双身份规则

依据[2023《金宝宝双身份规则 新版》](https://www.mistytown.cn/forum.php?mod=viewthread&page=1&tid=10611)：

| 项目 | 本项目选择 |
| --- | --- |
| 警长竞选平票 | 直接无警长；用户本次再次确认，不做 PK |
| 白天放逐平票 | 按原帖的警长投票对象裁决条件，不引入普通局 1.5 票 |
| 竞选日自爆 | 吞警徽；首夜已失效的狼人身份自爆后继续白天讨论，否则进入下一夜 |
| 自爆资格 | 当前身份具有自爆能力；潜伏在第二身份的狼不能凭实际阵营自爆 |
| 预言家反馈 | 用户最新规则覆盖原帖：第一夜查真实阵营，第二夜起查当前身份阵营；只反馈好人/狼人，不揭示角色 |
| 出局与胜负 | 双身份逐张失效；狼牌全失效或金宝宝全部完全出局的原版条件 |

首夜已失效狼人身份的自爆不再次扣除其第二身份，保留原帖“已在第一夜出局”情况下的特殊处理。首夜六人版没有狼刀；扩展版型的首夜刀口禁自爆不在当前版型范围内。

## 补足线下操作的约定

以下是把论坛规则变成现场手机操作的约定，不声称原帖规定了这些秒数或操作方式：

- 首夜结算后先私密收集上警/警下选择，竞选结束后自动公布夜间所有身份牌出局涉及的玩家号码。第一张牌出局也公告，同一人只唱号一次；只在没有掉牌时播报平安夜。公布前的候选资格、公开座位和测试 Bot 状态使用首夜前的状态，避免提前泄露。
- 报名 10 秒（用户最新指定），可在截止前修改；未提交视为警下。所有人提交后，房主也可结束报名。
- 警长竞选发言是单个不限时阶段，不记录发言人、不按座位轮转，由房主点击“结束竞选发言”进入最后 10 秒窗口。即使全是 Bot 参选，也等待房主结束该阶段。
- 发言期间和最后 10 秒窗口可退水；退水不可撤回，且不能因此获得警长投票权。每次有效退水实时更新名单并播报“X号玩家选择退水”，不自动结束整个发言阶段。
- 最后 10 秒同时允许合法狼人自爆；该窗口不能由房主提前跳过。投票阶段禁止退水与自爆。
- 只有最初在警下的玩家投警长票，投票 30 秒；可在截止前修改，超时未投视为弃票。所有选民提交后，房主可提前结算，截止后按座位公开选票。
- 无候选人则无警长；最后只剩一名候选人则直接当选；全员上警且最后不止一名候选人时，无选民可投票，因此无警长。
- 完全出局的警长有 30 秒移交或放弃警徽，超时视为放弃。身份仅失去一张时不移交。
- 白天讨论暂由房主手动结束。计时在服务端执行，断线或刷新不重新计时；服务器重启后以持久化的截止时间继续处理。
- 放逐投票窗口为 10 秒（用户最新指定），警长投票仍为 30 秒。语音开启时在引导播报后保留完整操作时长。

## 预言家操作

用户最新指定首夜查验真实阵营：目标两张牌中有狼人阵营身份即验为狼人，包括尚未生效的狼人、隐狼和复制狼。第二夜起仍查当前生效牌的阵营，当前隐狼为查杀。预言家第二夜才激活也按第二夜规则执行。私人记录保存当次查验依据；旧版本已经确认的记录不重新计算，没有依据字段的旧记录按当时的当前身份查验显示。

选择目标后必须点击“确认查验”。服务器立即保存和返回结果，私人查验记录在后续阶段、刷新及服务器重启后仍可查看。每夜每张有效预言家身份只能取得一次结果；重复确认同一目标不会重复记账，更换目标再次查验会被拒绝。房主和其他玩家接口均不返回此记录。

## 仍未完成的部分

夜间语音、固定时间轴、第二身份女巫、任意目标救药、独立药剂、全部指杀选择目标通灵、多执行者与夜间掉牌公告已实现。未完成：完整白天轮流发言与遗言、投降、拍刀。手机 Wi-Fi、锁屏与音频需要另外真机验收。

原帖「出局」将单个身份离开游戏也定义为出局；「公示」要求下一白天公告夜间出局号码。旧稿“只报两张都失效”的解读已撤销。原帖「女巫」明确救药可选任意角色、救药后丧失通灵；通灵是指杀的选择目标，不是死亡结果。

夜末按指杀、毒药、潜行依次完成所有已提交伤害，然后在公开时点发布结果和判定胜负。用户于 2026-10-30 明确：狼刀指向最后一个金宝宝，也不阻止女巫用毒或潜行者行动；所有技能照常生效，完整记录掉牌。只在本夜结算完后双方同时满足胜利条件时，按「狼刀在先」判狼人胜。绝不在狼刀阶段提前结束、取消后续技能。依据：[通用胜负判定](https://langrensha.net/news/20240905-8.html)；以用户这次确认的完整夜间结算语义为准。

## 通用狼人杀基础与双身份特例

补查来源：[法官流程](https://www.langrensha.net/strategy/2021092601.html)、[基础规则](https://www.langrensha.net/strategy/2021050801.html)、[女巫自救的不同约定](https://www.langrensha.net/strategy/2022121302.html)。这些资料存在版型差异，不把其一称作唯一通用标准。

| 项目 | 使用方式 |
| --- | --- |
| 发牌、夜间行动、首日竞选后报死、讨论、投票、判胜 | 通用流程作为基础 |
| 警下投警长票，退水者不因此获得选举权 | 沿用通用流程 |
| 狼刀在先 | 用户已明确采用；同夜双方胜利条件同时成立判狼人胜 |
| 警长平票 PK、警长票权加权 | 2023 版明确不同：竞选平票无警长、白天按警长所投对象破平票 |
| 女巫自救限制、解药只救刀口 | 2023 版救药可选任意合法角色，全程可自救；不套普通版限制 |
| 一次死亡就淘汰玩家、普通屠边胜负 | 双身份逐牌出局；两牌都失效才完全出局；狼胜目标是所有金宝宝 |
| 首夜狼刀、隐狼入群、守卫对毒药的保护 | 以 2023 六人明确技能为准，不替换成普通板角色技能 |

2026-10-30 用户已确认线下约定：狼刀按最高票目标结算，最高票并列则空刀；投票截止前可以反复修改，以截止时最后一次有效提交为准；白天发言由玩家自行组织，不要求自动法官控制轮流发言；遗言资格沿用原帖，但自爆没有遗言。这些是用户确认，不再标为 OPEN。

放逐导致两张牌完全失效后的遗言已实现：不限时，由房主结束后继续；必要时先移交警徽，再进入下一夜。若该次放逐达成胜负条件，遗言后宣布结果。只掉一张、自爆不进入此阶段。首夜完全出局的专用遗言、投降、拍刀仍未实现。
